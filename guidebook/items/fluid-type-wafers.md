A few kinds of fluid, each in bulk. Good for water, lava and the other fluids you pump all day. Like a [Type Wafer](type-wafers.md), but for fluids.

| Wafer | Each fluid holds, in buckets | Needs |
| --- | --- | --- |
| 2 fluids | 4,096 | vanilla items only |
| 4 fluids | 16,384 | Memory Chip |
| 8 fluids | 65,536 | Memory Chip |
| 16 fluids | 262,144 | Link Chip |
| 32 fluids | 1,048,576 | Advanced Memory Chip |
| 64 fluids | 4,194,304 | Synapse Core |
| 128 fluids | 16,777,216 | Synapse Core |

Every size is made from two wafers of the size before. They are used up, and the new wafer holds all of their fluid and starts unlinked. The 64 and 128 sizes need [Synapse Cores](synapse-core.md).

For mixed fluids with no limit on kinds, see [Fluid Capacity Wafers](fluid-capacity-wafers.md).
