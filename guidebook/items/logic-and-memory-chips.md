# Logic and Memory Chips

<Row>
  <ItemImage id="logic_chip" scale="4" />
  <ItemImage id="memory_chip" scale="4" />
</Row>

Logic and Memory Chips are the parts most JASM recipes are built from.

* A <ItemLink id="logic_chip" /> comes from an <ItemLink id="unquenched_logic_chip" />: cook a <ItemLink id="blank_chip" /> on a Campfire, then drop it in water.
* A <ItemLink id="memory_chip" /> comes from an <ItemLink id="unquenched_memory_chip" />: the same, but in a Blast Furnace.
* The whole stack cools at once, and no water is used up.
* Second-tier recipes need them, such as the Basic Deck and the 1K and 4K wafers.
* The Chip Workshop makes them too.
