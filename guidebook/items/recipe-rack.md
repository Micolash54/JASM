# Recipe Rack

<BlockImage id="recipe_rack" scale="3.5" />

A Recipe Rack holds 16 filled [Recipe Cards](recipe-cards.md). Every [Crafting Server](crafting-server.md) on the same network can use them.

| At a glance | |
| --- | --- |
| Holds | 16 cards |
| Uses | 2 FE a tick |
| Counts toward | the [machine limit](network-brain.md) |

Without power, the network can't see the cards inside, so autocrafting stops. Jade shows how many cards a rack holds.

Need more than 16 recipes? Add another rack.
