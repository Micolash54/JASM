A job needs room for its ingredients and for everything it makes along the way. That room comes from Storage Modules in the [Crafting Server](crafting-server.md).

| Module | Items of a job |
| --- | --- |
| 1k | 1,000 |
| 4k | 4,000 |
| 16k | 16,000 |
| 64k | 64,000 |

A server has four module slots, and their room adds up. If a job doesn't fit, the Deck says no server has enough modules.

## Making one

Each size is made from the one below it. 4k needs a Memory Chip, 16k a Link Chip too, and 64k an Advanced Memory Chip.
