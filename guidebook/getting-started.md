# Getting started

Everything JASM stores lives on **wafers**. Put wafers in a **Deck** and carry it with you, or link the Deck to a network of machines. An **Archive** keeps backups, so a lost wafer can be rebuilt onto a blank one.

To open this guide at any time, craft the [JASM Guide](items/guide-book.md).

## A first hour

1. [Grow Data Crystals](mechanics/growing-crystals.md) on a block of amethyst.
2. [Cut them into chips](mechanics/making-chips.md) by hand.
3. Craft your first [Capacity Wafer](items/capacity-wafers.md) and a Starter [Deck](items/decks.md).
4. [Befriend a wild Bitling](mechanics/befriending-bitlings.md) to unlock Link Chips and the [Chip Workshop](items/chip-workshop.md).

## How the tiers use the chips

The first tier of every item is made from vanilla items. From there on, recipes use JASM's own chips. Every higher tier needs the tier below it, and nothing it holds is lost on the way up.

| Tier | Needs | Examples |
| --- | --- | --- |
| First | vanilla items only | Starter Deck, Basic wafers, Data Cable |
| Second | hand-made Logic and Memory Chips | Basic Deck, 1K and 4K wafers, Crafting Server |
| Third | Link Chips from the Workshop | Advanced Deck, 16K wafers, Access Port |
| Top | Advanced chips from the Workshop | Elite and Ultimate Decks, 64K wafers |
| Beyond | Synapse Cores | the two biggest wafers of every kind |
