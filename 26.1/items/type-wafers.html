Type Wafers

26.1.2JASM 0.6.1

A Type Wafer holds only a few kinds of item, but a huge amount of each. Pick one for the things you collect by the thousand, like cobblestone.

WaferEach type holdsNeeds
4 types2,048vanilla items only
8 types8,192Memory Chip
16 types32,768Memory Chip
32 types131,072Link Chip
64 types524,288Advanced Memory Chip
128 types2,097,152Synapse Core
256 types8,388,608Synapse Core

What counts as a type

A type follows vanilla stacking. Items that don't stack, like tools and armour, each take a whole type to themselves. Save the Type Wafers for stackable things.

Upgrading

Every size is made from two wafers of the size before. They are used up, and the new wafer holds all of their items and starts unlinked. The 128 and 256 sizes need Synapse Cores.

For fluids, see Fluid Type Wafers.
